# Data Crawler — парсер маркетплейсов
Go-приложение для автоматизированного сбора и сравнения информации о товарах с крупнейших маркетплейсов РФ.

Собирает актуальные данные о ценах, рейтингах, остатках и продавцах с **Wildberries, Ozon, Avito и Яндекс Маркета**.

# Возможности
- **Многопоточный парсинг**. Параллельная обработка карточек товаров с контролем конкурентности;

- **Обход защиты**. Эмуляция реального браузера через chromedp для динамических страниц;

- **Кэширование**. Результаты парсинга кэшируются в **Redis**, сокращая время повторных запросов с 5-10 секунд до 1-5 мс;

- **Постоянное хранение**. Все результаты сохраняются в **PostgreSQL** для последующего анализа;

- **Быстрый просмотр**. Доступен быстрый просмотр в формате **JSON** в обход БД.


# Запуск и использование

## 1. Клонирование проекта

`git clone https://github.com/neoceann/DataCrawler.git`

## 2. Создание `.env` файла

На примере `.env.example` создайте `.env` файл со своими параметрами

## 3. Варианты запуска

### 3.1. Ручной

- Убедитесь, что у Вас установлен **PostgreSQL** (обязательно) и запущен **Redis** (необязательно, если не нужен кеш).

- Установите необходимые зависимости: `go mod download`

- Используйте `make` для сборки, или можно напрямую без бинарника: `go run cmd/app/main.go -params`

- `-params` - это набор флагов, который необходим для работы программы.
Подробную информацию можно найти, вызвав make info или обратиться к файлу напрямую.


### Пример запуска парсера

**Обязательно используйте кавычки, если строка содержит пробельные символы**

- После сборки: `./build/crawler -markets=wb,ozon -query="Коврик для мышки acer 250х200" -limit=7`

- Напрямую: `go run cmd/app/main.go -markets="wb, ozon, avito, yandex" -limit=10 -query="Коврик для мышки acer 250х200"`


### 3.2. Docker

### Сборка образов

`docker-compose build`

### Запуск инфраструктуры (PostgreSQL, Redis, миграции)

`docker-compose up -d`

### Запуск парсера

`docker-compose run --rm -params`

### Остановка

`docker-compose down`

### Пример запуска парсера

**Обязательно используйте кавычки, если строка содержит пробельные символы**

`docker-compose run --rm -markets=ozon,wb -limit=10 -query="Коврик для мышки acer 250х200"`
